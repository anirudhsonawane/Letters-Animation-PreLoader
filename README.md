# AYUSH — Brand Reveal

A minimal, cinematic brand reveal experience for **Ayush Pharma & Engineering**, built with Next.js, React, TypeScript and GSAP.

The project currently focuses on the opening visual experience — a custom `AYUSH` preloader with character-based transitions, GSAP Flip animations and a blue curtain reveal.

---

## ✦ Overview

The opening sequence is designed around the AYUSH wordmark.

The experience begins with:

- A full-screen blue visual background
- Large `AYUSH` typography
- Individual character-based animation
- GSAP Flip-powered layout transitions
- A controlled `S → U` horizontal movement
- A smooth blue curtain reveal
- A black Home page underneath
- Responsive typography for mobile devices

The final `AYUSH` wordmark remains visually positioned as the foundation for the upcoming Home page.
